허용하는 위치

광고를 켜더라도 홈의 일반 정보와 사용 가이드 목록·상세에 마련한 수동 슬롯에서만 표시합니다. 광고임을 분명히 표시하고 본문과 시각적으로 나눕니다.

준비한 Google AdSense 광고 형태

  • 홈: 화면 폭에 맞는 반응형 디스플레이 광고
  • 가이드 목록: 여러 콘텐츠 선택지를 보여 주는 멀티플렉스 광고
  • 가이드 상세: 읽는 흐름을 해치지 않도록 분리한 본문형 광고

각 위치는 한 형식만 허용하며 설정과 화면 선언이 다르면 광고 요청을 차단합니다. 앵커·비네트·사이드레일 같은 자동 광고는 민감한 앱 화면까지 따라갈 수 있어, Google 계정 승인과 페이지 제외 설정을 사람이 확인하기 전에는 사용하지 않습니다.

절대 사용하지 않는 정보

이름, 연락처, 생년월일, 정확한 위치, 피부 상태, 피하고 싶은 성분, 질환 추정, 검색어 원문, 루틴·체크인·모음·결정 기록은 광고 요청이나 광고 선택에 보내지 않습니다.

지역·종류·단가별 선택

신뢰할 수 있는 큰 지역 묶음, 필요한 동의 신호, 광고 종류, 운영자가 정한 최저 예상 단가, 최근 오류 상태를 모두 통과한 제공자 중 한 슬롯에 한 곳만 선택합니다. 지역을 알 수 없거나 계약된 제공자가 없으면 외부 광고를 표시하지 않습니다.

공급망·직접 캠페인·제한 공개

실제 판매자 행이 생기면 ads.txt, sellers.json과 광고 요청의 공급 경로가 같은 계정을 가리키는지 확인합니다. 직접 캠페인은 계약·승인·기간·지역·위치·일일 한도를 모두 요구합니다. 새 수익 규칙은 실제 송출 없이 먼저 계산하며, 이후에도 비교군을 남기고 최대 5%에서만 시작합니다.

표시하지 않는 위치

루틴, 내 기록, Plus, 개인정보·약관·쿠키·광고 선택, 지원, 오류·오프라인 화면에는 광고 슬롯을 두지 않습니다.

켜기 위한 필수 조건

  1. 실제 광고 게시자와 슬롯 ID 확인
  2. 법적 운영자 신원과 책임 연락 경로 공개
  3. 대상 지역에 맞는 인증 동의 관리 플랫폼 확인
  4. 신뢰할 수 있는 지역 분류와 제공자별 공식 연결 방식 확인
  5. 정책·데이터 흐름·속도·오류 중단 조건 검사 통과
  6. 최상위 공개 주소의 ads.txt 판매자 기록 확인

하나라도 없으면 코드가 광고 네트워크 요청을 차단합니다.
