광고·제휴 운영 원칙

현재 상태: 외부 광고·제휴 링크 꺼짐

허용하는 위치

광고를 켜더라도 홈의 일반 정보와 사용 가이드 목록·상세에 마련한 수동 슬롯에서만 표시합니다. 광고임을 분명히 표시하고 본문과 시각적으로 나눕니다.

절대 사용하지 않는 정보

이름, 연락처, 생년월일, 정확한 위치, 피부 상태, 피하고 싶은 성분, 질환 추정, 검색어 원문, 루틴·체크인·모음·결정 기록은 광고 요청이나 광고 선택에 보내지 않습니다.

표시하지 않는 위치

루틴, 내 기록, Plus, 개인정보·약관·쿠키·광고 선택, 지원, 오류·오프라인 화면에는 광고 슬롯을 두지 않습니다.

켜기 위한 필수 조건

  1. 실제 광고 게시자와 슬롯 ID 확인
  2. 법적 운영자 신원과 책임 연락 경로 공개
  3. 대상 지역에 맞는 인증 동의 관리 플랫폼 확인
  4. 정책·데이터 흐름 재검토와 자동·브라우저 검사 통과
  5. 최상위 공개 주소의 ads.txt 판매자 기록 확인

하나라도 없으면 코드가 광고 네트워크 요청을 차단합니다.
