먼저 백업

내 데이터 → 백업 내려받기를 선택하세요. 브라우저 데이터 삭제나 기기 교체 전에 백업을 보관하세요. 로그인 없이 사용하는 기록은 다른 기기에 자동으로 나타나지 않습니다.

확인 후 가져오기

새 기기에서 내 데이터 → JSON 백업 파일을 선택하고 찜 수를 확인한 뒤 합치세요. 지원하지 않는 파일은 기존 기록을 바꾸지 않습니다.
